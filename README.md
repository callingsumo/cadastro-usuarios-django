Cadastro de Usuários com Django

Sistema simples de cadastro de usuários, desenvolvido em Python com o framework Django e banco de dados SQLite.

Tecnologias utilizadas
Python
Django
SQLite
HTML/Bootstrap

Funcionalidades
Cadastro de novos usuários
Como rodar o projeto localmente

Clone o repositório:
   git clone https://github.com/callingsumo/cadastro-usuarios-django.git
   
Entre na pasta do projeto:
   cd cadastro-usuarios-django
   
Crie um ambiente virtual:
   python -m venv venv
   
Ative o ambiente virtual:
   venv\Scripts\Activate.ps1
   
Instale as dependências:
   pip install django
   
Rode as migrações do banco de dados:
   python manage.py migrate
   
Inicie o servidor local:
   python manage.py runserver
   
Acesse no navegador:
   http://127.0.0.1:8000/
